# Scope of bundled materials

The standalone starter includes original reference code, instructions, schemas and synthetic examples. It contains no third-party runtime packages, fonts, map data or user photos. assets/demos includes an AI-generated fictional example with its prompt and provenance receipt; it is not the original user's trip.

The optional Node.js runtime is not redistributed. Agent Skills, Agent Plugins and JSON Schema are referenced as external formats, not bundled implementations. Provider credentials, clients and commercial services are not included.

Users or contributors adding an image, font, map dataset, dependency or template reference must record its source and applicable license separately. A code license does not relicense those materials. The private proposal's actual-trip preview images are outside this starter package.

Generated demo assets retain their provenance. Their use remains subject to the selected generation service conditions; the code MIT license does not substitute for those conditions.
